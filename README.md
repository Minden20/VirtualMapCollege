# 🗺️ Interactive Map College

**Interactive Map College** — це проект, призначений для відображення інтерактивної схеми коледжу, по якій можна вільно переміщуватися. Програма дозволяє візуалізувати планування будівлі та навігуватися між кабінетами й поверхами.

---

## 🎮 Управління

Для переміщення по мапі використовуйте клавіші:

* **W** — Вгору
* **S** — Вниз
* **A** — Вліво
* **D** — Вправо

---

## 🧱 Елементи мапи

На схемі присутні спеціальні об'єкти:

* 🟨 **Жовті блоки** — позначають сходи/драбини. 
    * Використовуються для переміщення між різними поверхами коледжу.

---

## 🛠️ Технології

Проект реалізований за допомогою:
* **HTML** — структура та макет.
* **CSS** — візуальне оформлення блоків та поверхів.
* **JavaScript** — логіка переміщення та обробка клавіш.
